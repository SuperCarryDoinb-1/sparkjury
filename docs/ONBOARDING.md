# 新组员上手提示词

把下面这一句发给组员的 Agent（Claude Code、Codex、Cursor 都行）：

```text
克隆 https://github.com/VioletScar-Hui/sparkjury，先完整读一遍根目录的 AGENTS.md，然后严格按它开工。
```

一句话就够，因为规矩的本体只有 `AGENTS.md` 一处：开隔离工作区、走分支加 PR、每次提 PR 都在节点上部署验证、多人共用一台节点怎么避让、提交规范、红线，全在里面。这里不再抄第二遍——同一件事两处说法不一致，比只有一处更坏。

另外两句口头交代，发给人的时候单独说，不要写进提示词：

- 节点密码找队里要，不要写进任何提交、PR 或截图。
- 开工前先跟队长确认做哪一块，不要自己挑一个新的。
